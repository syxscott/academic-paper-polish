# 第一门：《论文写作规范与技巧》（43 页）

## 〇、★ Guide for Authors 的三种入口★

以 PPP（Palaeogeography, Palaeoclimatology, Palaeoecology，CiteScore 5.4 / IF 3.318）为例，**不限篇幅 SCI 期刊**的作者指南藏在三种不同入口：

| 平台 | 入口名称 |
|---|---|
| **ScienceDirect** 期刊主页 | "Guide for authors"（右侧投稿按钮旁） |
| **CellPress**（如 Current Biology） | 菜单里 "**INSTRUCTIONS FOR AUTHORS**" |
| **Elsevier Author Information Pack**（PDF） | TABLE OF CONTENTS 里的 "Guide for Authors"（p.4） |

→ **入口名称不统一，但内容都是同一份 Guide for Authors —— 它才是唯一权威格式来源。**

## 一、体裁与篇幅

| 体裁 | 篇幅 | 备注 |
|---|---|---|
| Articles | **5000–7000 词** | 4–8 个图 |
| Reviews | **8000–10000 词** | |
| Short Communications | **4000 词** | **<3 图表** |
| Comment / Reply | — | |

### 必备信息
- 通讯作者及邮箱
- 通信地址
- 文章元素：**Keywords / Figures / Tables / Citations**

### 其他事项
语言拼写、参考文献齐全、**授权许可**

### ★ Submission checklist
投稿前逐项核对（PPP Guide for Authors 原文）：
- **通讯作者**：指定唯一 corresponding author + **E-mail 地址 + 完整通信地址**
- **文件齐全**：Manuscript ✅ Include Keywords ✅ All figure captions ✅ All tables（含标题/描述/脚注）✅
- **正文图表引用与文件一一对应**（figure and table citations match the files provided）
- 印刷是否需要彩图要**明确标注**（Indicate clearly if color is necessary for print）
- Graphical Abstracts / Highlights（如适用）、Supplemental files
- Further considerations：已做 **spell check + grammar check**；**引用清单与正文双向一致**（all references cited in text ⇔ listed in Reference List）；**版权许可已取得**（含互联网来源）

## 二、文章结构与分级

### 标题分级
```
2 级：1.1
3 级：1.1.1   ← 个人不推荐过多分级
```

### 前置部分（顺序固定）
```
题目          → 准确、信息充足、避免缩写
作者及单位
通讯作者及邮箱
Highlights     → 亮点，<5 条，每条 85 个字符（含空格）
Abstract       → 300 词，避免缩写与参考文献
Article header → 每句首字母大写，而非所有单词首字母大写
Keywords       → 关键词，<6 个，避免与题目中的词重复
```

### 正文结构（★地学标准骨架）
```
Abstract
Introduction
Geological Background（Geological settings）   ← 地学特有
Materials and Methods
Results
Discussion
Conclusions
References
Acknowledgements
Tables
Figure Captions
Figures
```
⚠️ **Line numbers 行号，连续行号** —— 送审必查项
> PPP 原文：行号从 title page 开始，**贯穿正文 → 参考文献清单 → 图注**，用**连续编号**（continuous），**不要每页重新起号**

### ★ Graphical Abstract
- **可选**（optional），但能把内容浓缩在一幅图里、在目录里更醒目
- 尺寸：**最小 531 × 1328 px（高×宽）**，或按比例放大；**缩到 5×13 cm 用 96 dpi（屏幕）或 300 dpi（TIFF/PDF）仍可读**
- 作为**独立文件**在投稿系统单独上传（Summarize the contents… in a single concise, visual, self-explanatory way）

### ★ 关键词的"可检索性优先"原则
- **最多 6 个**，分号分隔（keywords separated by semicolons）
- **避免缩写和复数**（Only use standard abbreviations）
- ✅ **用具体检索词，别用泛称**：写 **"trace metal"** 而不是 "metals"；**"rare earth element"** 而不是 "rare earths"
- 判断标准：**"这个关键词是否会被拿去检索？"**（would a reader use it for a search for information?）—— 关键词的唯一作用是提高被检索到的概率

### ★ 标题分级的上限
- 十进制分级最多到 **3 级**（1. → 1.1. → 1.1.1.）
- 🔴 **Introduction 和 Discussion 禁止四级标题、禁止切得过碎**（"refrain from use of fourth-level headings and too much subdivision…often with each consisting of just a paragraph or two"）—— 切碎会破坏论证连贯性，**提出假设→展开论证→整合结果**需要连续篇幅
- 交叉引用写 "**see Section 2.3.2**"，不要写 "see below"

### ★ 研究点位坐标规则
- 所有 study sites 给出**国际经纬度**（international lat–long / degree–decimal / degree–minute–second），**不能只写地名**
- 点位 **≤10 个**写进正文；**>10 个**做成表

## 三、★ 各部分的引文密度要求★★ 最实用的一张表

| 章节 | 引文要求 |
|---|---|
| **Introduction** | 除了**问题和过渡句**，其他的**都要有参考文献** |
| **Results** | **几乎没有**参考文献 |
| **Discussion** | **每段 5–8 句** = topic sentence + **有文献标注的 3–4 句** + **有自己数据支撑的 2–3 句** |

### 常见明显错误（自查清单）
| 章节 | 错误 |
|---|---|
| Discussion | 整段**没有任何参考文献**（是 results 的重复？） |
| Discussion | 整段**没有自己数据实验**、全是参考内容（写成 review 了？） |
| Results | 夹杂了太多**已发表的（带文献的）数据**（应放到 Discussion） |
| Abstract / Conclusion | 里有**不少文献**（不应出现） |
| Introduction | **缺少参考文献**（常识性科普？）+ **没有提出明确问题**（科学意义不明确） |
| Materials and Methods | 缺少参考文献和标准流程（自创？没认可度）+ 缺少细节（**别人无法重复**） |

## 四、段落结构

- **Topic sentence 开头**，总—分结构
- ⚠️ **1–2 句话的段落是非常差的结构**；**5–8 句最合理**
- **换了对象主体就分段论述** —— 一段集中讲清楚一个问题/对象

## 五、地学常见坑★

### 时间单位
| 单位 | 用法 |
|---|---|
| **Ma / ka / Ga** | "millions/thousands/billions of years **ago**"——**绝对年龄**（距今） |
| **Myr / kyr / Gyr** | "**duration**"——**持续时长**（时间跨度） |
| **m.y.** | 年龄 **>2500 Ma** 的用 'm.y.' 不用 'Ma' |
| **ka B.P.** | 🔴 **冗余**（ka 本身就是"千年前"）；第四纪研究 'k.y. B.P.' 可以 |
| **cal. B.P.** | 校正年龄用 **cal. B.P.**（calibrated years B.P.），近 50,000 年内日期按惯例必须校准 |
| **>12 to 6 ka（= 6 to 0 Myr）** | 第四纪研究的时间写法示例 |

### Early/Late 与 Lower/Upper
- 'basin subsidence during the **Late** Cretaceous'（时间）vs 'the negative δ¹³C trend through the **Upper** Cretaceous'（地层）
- **Early/Late = 时间**（年代）；**Lower/Upper = 岩石**（地层）
- 小写 vs 大写：'early Miocene'（形容词）vs '**Early** Miocene'（正式地质年代单位）
- 'early/late' 用于时间时小写；正式单位 'Early'/'Late' 大写

### 参考文献引用格式
- 正文括注：**(Smith, 2011)** / **(Smith and Johnson, 2002)** / **(Smith et al., 2003)**
- 叙述式：Smith (2011) showed that… / Smith et al. (2003) showed that…
- **同一作者多篇**：年份后加 a/b/c（Smith, 2001a; 2001b），正文引用和文献清单都要
- 同一作者多篇的排序：**先按年，再按 a/b/c**（Smith 2001a, Anderson et al., 2010; Johnson, 2014）
- **不同作者按字母序**，用分号分隔：**(Smith, 2001; Anderson et al., 2010; Johnson, 2014)**
- 同年同姓**不同第一作者**：加**首作者姓名首字母**区分——**(Wang C.- et al., 2010) vs (Wang H.-Y. et al., 2010)**

### 段落写作
> All papers should be written to communicate with readers in order to **enjoy your paper**.
- **每段一个中心思想**（developing a single idea in each paragraph）
- **Topic sentence 放段首**，**不含数据、不含文献**（without data or literature citations）——先陈述核心观点
- 其余句子展开论证：自己的数据 + 他人文献，逻辑递进
- **段尾过渡句**让读者能顺利滑进下一段的 topic sentence
- Discussion 段尤其如此——**提出假设→逐层论证→小结**，逻辑清晰才易被审稿人接受

### Quality of English
- 所有录用稿件必须达到 **professional-level English**（受过教育的非母语读者能看懂）
- PPP **强烈建议投稿前就润色英文**——**好读好懂的稿件通常评审更顺利**

- **Ma 与 Myr 的区别**（年龄单位）
- **岩石与年代地层**的区别：**Early Triassic vs Lower Triassic**（岩石/岩石地层单位 vs 年代地层单位）
- ⚠️ **"Middle Cretaceous" 对不对？** —— 答：**不对**，应为 **Middle Cretaceous 的正确用法需谨慎**；Cretaceous 属 **Period（世）**，白垩系下分 Upper/Lower 而非 Middle/Upper；"Middle Cretaceous" 是**非正式/误用**说法，规范应为 *Upper Cretaceous* 或 *Lower Cretaceous*，或用 *mid-Cretaceous*（作形容词时）
- **参考文献引用格式**：一个作者 / 两个作者 / 三个作者 / 不同作者 / 不同文献的区别

## 六、图件规范★★ 实操参数

### 格式与分辨率
| 图类型 | **最低分辨率** |
|---|---|
| **Halftones 照片**（灰度/彩色照片） | **300 dpi**（TIFF/JPG） |
| **Bitmapped line drawings**（位图线条图） | **1000 dpi** |
| **Combination art**（线条+照片混合图） | **500 dpi** |

| 项 | 要求 |
|---|---|
| 格式 | TIFF / JPG（**EPS 不推荐**；多面板图先单图转 PDF 再合并） |
| 单图大小 | **<10 MB** |
| 总文件 | **<50 MB** |
| 图中字体 | **sans serif：Arial、Helvetica；或 Times New Roman、Symbol、Courier** |
| 图中文字 | 最小字号应足够清晰，不被线条/底纹遮挡 |
| 屏幕优化格式 | 🔴 **禁止 GIF / BMP / PICT / WPG**（分辨率太低） |
| 过度处理 | 🔴 Substantially manipulated or low-resolution **不予接收** |
| Data Availability | 鼓励设专节，"visible in ALL reading formats"，指向**任意公开仓储** |
| Funding 语句模板 | "This work was supported by the [Agency] (grant numbers xxx, yyy); …" |
| Footnotes | 少用，**全文连续编号** |

### 图件宽度（PPP 是双栏期刊）
- 单栏宽度 **<85 mm**
- 双栏宽度 **<180 mm**
- 极少数情况横版满版

### 电子制图 7 个要点
1. 保持原有大小
2. 使用推荐字体符号
3. **按照在文章中出现的先后编号**
4. 给图文件按顺序编号命名（PPP 原文建议命名如 "**Smith-Figure1.tif**"）
5. 提供 **figure caption（图注）**
6. 单个图 <10 MB
7. ⚠️ **不要分辨率太小、版面过大**

### ★ 图内规范细节
- **Figure numbering**：按正文出现顺序编号；正文中**首次提及处**引用（even at first mention）；补充图 "Figure S1" 等；**高分辨率（600 dpi）出版就绪版本**可另附（optional）
- **Panel labels**：用**大写字母 A, B, C…**；放在**每个面板的左上角或左下角**；同一图内位置模式一致；🔴 **不要给标签加括号/方括号/框**
- **Figure captions**：一句简明描述性标题 + 解释所有符号缩写；**引用来源放图注**；🔴 **图注不要重复图内已含的信息**（duplicated information may confuse readers）；同一地层柱在多图中**不要重复出现**
- **Plates 图版**：🔴 **PPP 不允许 Plates**——过去作为图版的内容（如化石标本图像集）一律作为 "Figure" 提交
- **Maps**：🔴 **不得显示有政治争议的边界**（politically disputed boundaries）
- **彩图**：鼓励用彩图（增强表达）；**在线版免费彩印**（ScienceDirect 等）；**印刷版彩图收费**（optional，录用时决定）

### 版权与合规（红线）
- **推荐使用彩图**
- **图注要详细** —— **只看图注就能把图看明白**
- ⚠️ **不使用有政治分歧的地图等**（涉及国界/主权标注）
- 🔴 **严禁直接粘贴复制某个已经发表的图**（除非 Open Access 或已获专门使用许可）；**修改后必须标注文献来源**

### 表
- 在**表上**（而非只在上方）有一句表名

## 七、结论与参考文献

**结论**：推荐 **1–2 个段落**，简短地介绍全文中最重要的结论
> PPP 原文：Conclusions 应**一段，最多两段，且总长不超过 30 行**（no more than 30 lines total）——对主要发现的简明总结

### 参考文献清单需涵盖
期刊文章、书和专著、网页、数据库

### 排序规则
- ⚠️ **按字母排序**（References must be organized alphabetically）
- **同姓不同名**：按名排序——Smith, A. 的所有论文排在 Smith, B. 之前
- **同一第一作者**的三层排序（PPP 原文明确）：
  1. **全部单作者论文**最先，按出版年从旧到新
  2. **Smith & Johnson 双作者**随后，按第二作者姓氏字母序
  3. **多作者论文**最后，按出版年
  > 理由：读者检索时**按年份找**（正文括注里没有第二作者名），不是按第二作者找
- 同一作者多篇按年 + a/b/c（见 P7 引用格式）

## 八、★ 如何找格式范例★

**参考目标期刊近 3 年内发表的相似论文，或者相近的最新论文 pre-proof 版本。**

- 检索入口：期刊主页 **Articles in press** → *Latest published* → *Top cited* → *Most popular*

- ⚠️ **Pre-Proof / in press / MS**：**多参考几篇，有些文章也有少量不符合要求的地方（自己要取长补短）**

## 十、★ 为什么格式这么重要★

## 十一、★ Word 操作与制图硬参数★★ 极实操

### 页面设置
| 场景 | 尺寸 |
|---|---|
| A4 | **210 mm × 297 mm** |
| **SCI 稿件中等边距** | **38.2 mm × 50.8 mm** |
| **图表的要求** | **160–180 mm × 210–230 mm** |

- 推荐 **12 号字、双倍行距、编行号和页码**

### 🔴 Word 缩放铁律
**Word 里插图表，禁止拉对角线缩放！**
**从制图 → 导出 → 最后插入 Word，全程严禁拉对角线或者等比例缩放！**
（会破坏图元比例与分辨率）

### 制图尺寸与字号
| 项 | 参数 |
|---|---|
| 设计尺寸 | **≤180 mm（宽）× 230 mm（高）** |
| **线条粗细** | **0.25 与 0.5 mm 组合** —— 太细看不清，太粗显粗莽 |
| **字号大小** | **10 号与 6 号组合** ／ **12 号与 8 号组合** |
| 数字文字下限 | 🔴 **严禁出现小于 4 号** |
| 数字文字上限 | **不推荐大于 12 号** |

### 构图
- **黄金比例（三分之二原则）**
- 精确的黄金分割比例 0.618…；比值等于较小部分与较大部分的比值
- 三种写法：精确的黄金比例 / 艺术性、知道性 / 蓝眼蜂等类型的类比值
- ✅ **黄金分割法优于三分法**：黄金分割构图是水平或竖直的**三分之二**，主体边线通常位于三分线上（简易构图），**具有构图均衡的优美性**

### 对称与不对称美感
- **对称**：适合表达严谨、稳定、平衡的结论（例：Liang et al., 2016, PPP —— 化石标本整齐排列）
- **不对称**：适合表达变化、动态、演化过程（例：Fu et al., 2020, Science）
- → 🔴 **p30 右图正是放射虫化石镜下照片**（Fu et al., 2020, Science）

### 色调
- 搜索"**sci 论文配色**"找配色网站
- 示例色块与折线配色范例（Biofeedback / No biofeedback 对比柱状图）
- 参考：网易订阅频道《学习SCI论文图片配色，这几个超美的SCI绘图配色网站要收藏好！》

## 十二、★ 时间预算：分解目标★★ 最落地

每天写 2–3 句（一句约 15 词） → 20–30 天完成正文

## 十三、★ 学位论文写作★

### 写作规范文本
以《**某高校研究生学位论文写作规范**》（研究生院，2015 年 12 月）为范本，三章 + 附件：
```
第1章 内容要求：中文封面 / 英文页 / 论文类型与密级标注 / 标题摘要关键词页 /
        独创性声明 / 附件 / 中文摘要 / Abstract / 目录 / 图和附表清单 /
        正文 / 致谢 / 参考文献 / 附录
第2章 书写要求：文字、标点、符号与数字 / 名词和术语 / 图 / 计量单位和符号 /
        公式 / 参考文献标注 / 图表编排
第3章 排版及印刷要求：纸张和页面设置 / 字体字号 / 图表 / 中英文及标点 /
        页眉页码 / 图表编排 / 其他
附件：中文摘要页、英文摘要页、独创性声明、致谢、授权书、作者简历、
      目录、图表清单、表格样式、参考文献、论文封面样式
```

### 书写细节
- **文字**：简体中文；不使用已废弃的繁体字/异体字；数字用法执行 **GB/T 15835-1995《出版物上数字用法》**

## 一、为什么要做文献综述

### 科学研究定义
> 科学研究（Scientific research），一般是指在发现问题后，经过分析找到可能解决问题的方案，并利用科研实验和分析，对相关问题的内在本质和规律而进行的**调查研究、实验、分析等一系列的活动**，为创造发明新产品和新技术提供理论依据，或获得新发明、新技术、新产品。科学研究的基本任务就是**探索、认识未知和创新**。

（英文定义来源：Purdue University, College of Science — *What is Research?*）
> *Research is the process of discovering new knowledge through the process of discovery.*
> 四个要素：diligent inquiry（勤勉探究）+ systematic observation of phenomena（系统性现象观察）+ experimentation（实验）+ testing the effect of changing conditions（检验条件改变的效果）

## 五、★ 三个核心方法★

### 1. 积累自己的素材库
> **同一小主题精读 + 粗读文献，PPT 合集**

**实例**：
- 主题：***

- 其他文献**只保留了相关图**
- → **49 张 PPT 素材库**

### 2. 积累自己的写作技巧参考库
**形式 = 英文原文 PDF + 逐段中文批注对照**。以 *Latest Permian paleosols from Wapadsberg Pass, South Africa: Implications for Changhsingian climate*（GSA）为示范，在 INTRODUCTION / MATERIALS AND METHODS / RESULTS 各段旁批注"这段好在哪"：
- INTRODUCTION 段旁：*阐述地质背景与前期研究的联系；写明自己的研究目的、测量对象和意义*
- METHODS 段旁：*每个方法一段，清晰明了（对应对素材库"精读"的 paragraph-level 拆解）*
- RESULTS 段旁：*每个指标逐一说明来源和用途，逻辑直观、适合快速参考*
> 方法本质：**把好论文拆到段级并写出"为什么好"**，积累成自己的句式与结构库。

### 3. 辨证思维训练
> **学其所长，避其所短，为我所用**

P35 展示了一份真实的批判性阅读笔记（原文 + 批注）：
```
感受：
1、introduction 部分逻辑非常清晰，能从大类引出研究材料和目的，
   也是从每段引出段落，有非常不错的参考价值
2、method 部分对于方法的介绍非常仔细，每个方法一段，清晰明了
3、result 部分对每个指标的不同的主观的描述，做了详尽的测试，
   对每个指标的来源和用途这样在一一说明很并阐述，逻辑直观
   非常适合快速阅读和参考信息
4、discussion 显示出作者丰富的阅读量，即使材料不多，但对于每个
   指标的分析都非常深入，与前人研究进行了非常多的对比，且 topic
   sentence 非常清晰，有的也很精炼，但能简洁表达出本段内容，段落
   很多，段落很短，且在段中段结尾也常用 hence 来做个小结

但就小标题来看，前两个小标题虽然不是具体内容，而是根据测试方法来
分段，最后一个没按内容（大气 CO2 浓度）来分析，似乎不太好。
```
> 训练目标：**每篇文献都要同时写出"好在哪"和"哪里不好"**——这是综述里"评述"而非"罗列"的基本功。
