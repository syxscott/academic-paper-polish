# 配色系统与视觉编码（Color System & Visual Encoding）

> **本文件解决什么问题**：`figure-specs.md` 给的是**硬参数**（dpi / 尺寸 / 字号上限）。
> 本文件给的是**配色决策逻辑** —— 面对一张新图，该选哪几个颜色、按什么规则排、
> 同一张图里颜色怎么保持一致。
>
> **来源**：Cell 2026;189:5396-5410.e8（VIDA 抗病毒 mRNA 平台）、
> Cell Metabolism（MTDH-肝脂代谢-CD8⁺ T 细胞）、
> Cancer Cell 2026;44:1549-1567.e12（PD-1 blockade / TLS）三篇顶刊 Figure 的配色与版式拆解。
> 观察对象是**配色如何组织**，不是具体色号。

---

## 🔴 铁律：配色是语义系统，不是审美选择

最常见的错误：把配色当成"好看不好看"。
实际上顶刊配色是一套**编码系统** —— 读者靠颜色在 3 秒内判断
「哪个是对照、哪个是处理、哪个是上调、哪个是下调」。

**判据**：把你的图给同门看，问"哪组是对照？"。
如果需要看图例才能答 → 配色失败。

---

## 一、🔴 第一原则：色相必须在全图可追溯

**所有实验图的第一层编码是「组别」，不是「数值大小」。**

真正的铁律只有一条：**同一个颜色在全图所有面板中必须代表同一组。**

> 🔴 **可检验标准**：拿掉图例，只看颜色，能否在所有面板中一致判断组别？
> 做不到就是配色失败 —— 这是唯一的硬标准。

### 「对照冷色 / 处理暖色」是常见约定，不是规则

Cell 系列常见「对照=蓝灰、处理=粉」，视觉上对照退后、处理前进。
但**并非顶刊通例** —— Cell Metabolism 的 WW（对照）用红、KK（处理）用蓝，
与前者相反。

**因此正确的做法**：
- 优先沿用**目标期刊近 3 年**的惯例（同一刊的读者有肌肉记忆）
- 若自行选定，则**全图 + 全稿**保持一致
- 不要因为"冷=对照更符合直觉"就换掉已投/已投过版本的方案

### 多组时的分配原则

| 组数 | 分配方式 |
|---|---|
| 2 组 | 对照一个色相，处理另一个；**色相不同、明度相近** |
| 3 组 | 三个色相 + 明度等距（保证灰度可分） |
| 4 组及以上 | 🔴 **色相编码主变量，明度编码次变量**（见 2.3），避免四色平铺 |

**为什么必须固定**：一个 Figure 里出现 6 个面板，
如果面板 A 的蓝色是 WT、面板 B 的蓝色是处理组，
读者必须反复回查图例 —— 这是顶刊 Figure 绝对不会犯的错。

### 阴性对照 / 无效组：用「空心」而非第三种颜色

第三色（Mut、mutant 等）**不必另配色**，用**空心标记**即可：

```
● 实心  = 有实际效应 / 有显著差异
○ 空心  = 阴性对照 / 无显著差异（ns）
```

**共同点**：空心表示「**预期中的无效应**」。
这比给 Mut 单独一个颜色更省认知成本 —— 读者一眼就知道
"空心那组本来就该没反应，它有反应才是问题"。

## 二、色相选择的具体锚点（可直接抄）

### 2.1 两组对比（最常用）

| 组别 | 填充色 | HEX | 描边/线 |
|---|---|---|---|
| 对照 | 粉 | `#F5C8DD` | `#E08D8B` |
| 处理 | 蓝 | `#9DC3E6` | `#4758A2` |
| 第三组 | 浅黄 | `#EDE7C4` | `#E4DF5F` |

> 这三个值与 `figure-specs.md` 的七色表同源（`#E08D8B` 粉红、`#4758A2` 深蓝、
> `#E4DF5F` 黄），可直接替换使用，不必另记一套。

### 2.2 三组及以上（遗传学三态）

顶刊最常见的基因型三态配色：

| 基因型 | 颜色 | HEX |
|---|---|---|
| `+/+`（WT） | 珊瑚红 | `#F8766D` |
| `+/−`（杂合） | 琥珀黄 | `#E7B800` |
| `−/−`（KO） | 青绿 | `#00BA38` |

**判据**：三色必须在**明度上等距**，这样打印成灰度后仍能区分。

### 2.3 四组（干预矩阵）

四组对比时用「**色相两两成对 + 明度区分**」，不要四种色相平铺：

```
橙  PBS-WT        ▓▓▓  深橙填充
橙  CM-WT         ░░░  深橙浅填充（同色相 = 同条件）
绿  PBS-KO        ▓▓▓  深绿填充
绿  CM-KO         ░░░  深绿浅填充（同色相 = 同条件）
```

**规则**：**色相编码主变量，明度编码次变量**。
这样读者一眼看出"蓝和绿是 KO，浅深是处理与否"。

## 三、🔴 一个通道只能承载一个变量

一张图里，同一视觉通道**只能承载一个变量**。

| ❌ 错误用法 | 后果 |
|---|---|
| 蓝色既表示"对照组"又表示"另一组处理" | 读者无法解码 |
| **柱/折线图**里颜色深浅表示数值大小 | 数值已由 Y 轴表达 → 重复编码是噪音 |
| 不同面板用颜色区分**数据系列**，但面板间含义变了 | 全图失去可比性 |

**检验**：列出图中每个颜色的含义 —— 如果同一颜色对应两条不同含义，重画。

### 🔴 但气泡图是例外：颜色深浅 = 显著性是对的

富集分析气泡图（GO / KEGG / pathway bubble plot）**同时用三个通道**：

```
颜色深浅 = −log₁₀(p)      显著性
圆点大小 = Gene Count     基因数
X 位置  = GeneRatio       富集比例
```

这**没有违反**「一通道一变量」—— 因为 Y 轴已经表达了 GeneRatio，
颜色被"腾"出来表达显著性。**关键是：轴用了什么，颜色就不能再用什么。**

### 背景色块只表类别，不参与数值编码

多通路/多类别列表常用**背景色带**做分区（如把 12 条通路按
「上游信号 / 抗原处理 / 免疫应答」染成三条粉/绿/黄底色带）。

🔴 **色块只表示"这一段属于哪一类"**，不代表数值、不参与图例色阶。
判断标准：把色块去掉，信息应减少（类别归属丢失）而非改变（数值解读改变）。

## 四、🔴 荧光/多通道图的通道色是固定约定

显微图、荧光图、叠加图的通道色**全球通用约定**，不能自创：

| 通道 | 颜色 | 典型含义 |
|---|---|---|
| 1 | **绿** | 目标蛋白 / FITC / 自发荧光 |
| 2 | **红** | 第二标记 / Cy5 |
| 核 | **蓝** | DAPI / Hoechst |
| 线粒体 | **洋红/品红** | MitoTracker |
| 叠加 | **青** | 绿 + 蓝 |
| 叠加 | **黄** | 绿 + 红 |

**配套要求**：
- **色标文字写在图像正下方**，颜色与通道一致（如 `VIDA/DAPI` 中 VIDA 用绿、DAPI 用蓝）
- 叠加通道名之间用 `/` 分隔，不用空格
- 不用颜色区分的实验，必须提供灰度图或明度差版本

### 显微图的配色陷阱

🔴 **不要用红/蓝、红/绿、蓝/绿、蓝/黄作区分色**。
约 8% 男性有色觉缺陷，红绿并置对他们完全等价。
`paleobiology-journal.md` 已列此条，此处强调其在荧光图中**尤其致命** ——
因为荧光图的信息全压在颜色上。

**安全做法**：区分色**始终配第二重线索** ——
形状（● / ▲ / ■）、线型（实线 / 虚线）、或直接在图上标文字。

---

## 五、🔴 连续型数据用色阶，不用分类色

热图、表达量矩阵、相关性图这类**连续变量**：

| 错误 | 正确 |
|---|---|
| 用红-绿渐变（0 → 高） | 🔴 用**蓝-白-红**发散色阶（低 → 高 = 低 → 中性 → 高） |
| 彩虹色阶（jet） | 🔴 用**感知均匀色阶**（viridis / Blues / RdBu） |

**理由**：红绿渐变在色觉缺陷者眼中丢失方向；
彩虹色阶在中间区产生**人为的假边界**（黄区视觉上被放大）。

### 发散色阶的两个硬要求

**① 必须以 0（或中位数）为中性色中心**

比较两类数据时（KO vs WT），色阶**必须以 0 为中心**，
两侧用**同饱和度的两个色相**，而不是深浅同一色相。

**② 🔴 必须带色标条，并标明数值方向**

同一篇论文里不同热图的色标方向**可能相反**，读者无法靠猜：

| 图 | 变量 | 色阶 | 方向 |
|---|---|---|---|
| 基因表达热图 | log₂ fold change | 蓝 — 白 — 红 | 上调=红 |
| 代谢物丰度热图 | 相对丰度变化 | **橙 — 白 — 蓝** | 升高=橙 |

**规则**：每张热图**右侧或下方**必须有：
- **色标条**（渐变条）
- **两端数值**（如 `1.9` ← `0` → `−2.5`）
- **变量名与单位**

⚠️ 没有色标条的热图，等于让读者自己猜哪个方向 —— 直接扣分。

## 六、🔴 背景色：不用纯白，用浅灰或浅蓝

顶刊多面板图的底色**极少用纯白**，常用**极浅冷灰/浅蓝**：

| 用途 | 推荐底色 |
|---|---|
| 分组区分（左右分屏） | 左 `#F0F4F8`（冷蓝灰） / 右 `#FAF0F0`（暖红灰） |
| 通用面板底 | `#F7F7F7` 或 `#F2F2F2` |
| 强调某一面板 | 浅色填充，其余留白 |

**判据**：如果你要靠底色区分两组实验，用两个**色温相反的极浅色**
（冷蓝灰 vs 暖红灰）—— 而不是灰和深灰。色温比明度更能传达"对立"。

⚠️ **但化石标本照片例外**：底色必须**纯黑或纯白**，不用浅灰 ——
标本本身的颜色就是数据，任何色偏都会污染判读。

## 七、图内标注配色

| 元素 | 规则 |
|---|---|
| **显著性星号** | `****` 放数据点/柱顶上方，**用黑色或深灰**，不随组别变色 |
| **p 值** | 同样深色，横线（bracket）用灰 |
| **对比箭头** | 🔴 **红↑ = 升高 / 绿↓ = 降低**，替代文字描述 |
| **箭头颜色例外** | 抑制位点用红（⊣）、激活位点用绿（→） |
| **示意图中的基因/蛋白名** | 用**红/绿斜体**，仅在机制示意图中出现 |

> 🔴 **星号不要染色**：染色后读者会误以为它属于某个组别。
> 显著性标注是"跨组"的统计结论，必须用中性色。

## 八、🔴 基因型/条件用「色温编码」而非图例

**顶刊最省读者认知成本的做法**：把组别直接编码进版面。

```
┌─────────────────┬─────────────────┐
│  MTDH-WT        │  MTDH-KO        │   ← 顶栏底色：冷蓝 / 暖红
├─────────────────┼─────────────────┤
│   实验数据      │   实验数据      │
└─────────────────┴─────────────────┘
```

**收益**：读者不需要在 6 个面板间来回对照图例。
顶栏颜色 + 文字标签，双重编码。

**规则**：
- 分屏用**色温相反的极浅底色**（冷 vs 暖）
- 顶栏写组别名，**字号与面板字母一致**
- 全图所有分屏图**用同一套配对**（WT 用同一色、KO 用另一色）

### 🔴 更省空间：图内符号矩阵

对比实验（尤其 2×2 设计）**不必画图例框**，直接在坐标轴上方压一个符号矩阵：

```
VIDA:    +    +    -
NS2B3:   -    +    +          ← 行=基因型/处理，列=条件组合
```

**收益**：一眼看懂对照设计，且不占图外空间。
Cell / Cell Metabolism / Cancer Cell 均采用此法。

### 🔴 小倍数图（small multiples）共用一个图例

一组小图（如 8 个血常规指标）排成一行时：
- **图例只放最右侧一个**，不要每个小图重复
- 每个小图上方标 `ns` / `****` / `p=0.013`
- 轴标题统一用同一字号

### 🔴 组别顺序必须与图像阵列一致

免疫组化（IHC）/ 显微照片阵列（如 5 组治疗 × 3 标记）：
- **组名在上方、标记名在左侧**，排成规则矩阵
- 🔴 **标签顺序必须与统计图图例的颜色顺序完全一致**
  （图例：黑/蓝/橙/红/深红 → 阵列也按此顺序排列）
- 否则读者要在"图例的第三组"和"照片的第三列"之间做心算

## 十、🔴 与地学/古生物图件的适配

上述规则源自**分子生物学湿实验图**（免疫荧光、WB、流式、单细胞）。
迁移到地学时，**结构规则保留，通道色规则不适用**：

| 规则 | 湿实验 | 地学/古生物 |
|---|---|---|
| 色相全图可追溯 | ✅ | ✅ |
| 色相编码主变量、明度编码次变量 | ✅ | ✅ **尤其适合**（如：属 = 色相，种 = 明度） |
| 左右分屏冷暖底色 | ✅ | ✅ 直接用 |
| 图例顺序全图一致 | ✅ | ✅ |
| **荧光通道固定色** | ✅ 核心规则 | ❌ **不适用**（无荧光） |
| **红绿并置禁忌** | ✅ | ⚠️ **降级为建议**（黑白印刷占比高，但地学图常需彩色区分） |
| **连续色阶必须感知均匀** | ✅ | ✅ 直接用（如：古温度/古盐度恢复图） |
| **图内符号矩阵标注组别** | ✅ | ⚠️ 少用（地学多为单组对比，用分组标题即可） |
| **小倍数图共用图例** | ✅ | ✅ 直接用（如：多个剖面/多个 taxa 对比） |

### 🔴 地学场景的特殊注意

- **地层柱状图**：同一地层单元在全图必须**同色同明度**；
  颜色编码地层时代，**绝不编码岩性**（岩性用花纹）
- **化石标本照片**：底色用**纯黑或纯白**（不是浅灰），
  标本本身颜色即数据，不能加色偏
- **对比度**：地层柱状图若同时用颜色 + 花纹编码两种维度，
  印刷后极易糊成一团 —— **优先只用一种**
- **色觉障碍**：地学图常用红/绿区分古环境（如氧化还原、温暖/寒冷），
  此时**必须**配第二重线索（花纹、线型、直接标注）——
  与 `paleobiology-journal.md` 的色彩避坑条一致
