# 模块 5 · 结果润色（Results）

> 适用：结果章节 + 图表规范检查。核心原则：**Results 只讲"发现了什么"，"为什么"留给 Discussion**。

```text
请优化我的结果章节，确保结果的呈现客观、清晰，并符合学术图表规范。

- **客观性陈述**：审查结果描述，剔除所有主观性、解释性或推测性语言（例如「惊人地发现」「出乎意料的是」「这似乎表明」）。确保本章节只专注于客观报告「发现了什么」，将「为什么」和「意味着什么」留给讨论部分。
- **逻辑结构**：检查结果的呈现顺序是否与研究问题或假设的提出顺序保持一致，确保逻辑清晰、便于读者跟随。
- **图表引用与说明**：确保文中对每个图、表均有明确引用（如「如图 1 所示」）。检查图标题和表标题是否简洁、信息量充足。对图表中的关键元素（坐标轴、图例、单位、缩写）是否有清晰说明，无需读者反复查阅正文。
- **图表类型检查**：检查图表类型是否与数据类型匹配（如分类变量用柱状图、连续变量关系用散点图、趋势变化用折线图）。如发现类型不匹配，请提出替换建议并说明理由。

请处理以下结果章节内容（可附带图表描述）：【此处粘贴你的结果初稿】
```

## 🔴 Results vs Discussion 的组织差异

同一批结果，在两部分用**不同坐标系重组**：

| | 组织逻辑 | 范例结构 |
|---|---|---|
| **Results** | 按**产物 / 表征手段**平行铺开 | 3.1 OH 产率 · 3.2 H₂O₂ 产率 · 3.3 Fe²⁺ + SO₄²⁻ · 3.4 XRD/SEM-EDS/XPS · 3.5 底物氧化 |
| **Discussion** | 按**机理**收拢 | 4.1 无氧氧化机理 · 4.2 有氧氧化机理 → 4.2.1 H₂O₂ 生成与分解 / 4.2.2 各路径相对贡献 / 4.2.3 机理汇总 · 4.3 环境意义 |

### 期刊差异（动笔前必须确认）

| 期刊 | 要求 |
|---|---|
| **GCA** | Results 与 Discussion **必须分离**，各自独立编号；Results 只提供数据与观测，**不讨论机制** |
| **ES&T** | **合并**为 Results and Discussion；*Be complete but concise* |

---

## 🔴 引文密度：Results 几乎没有参考文献

| 错误 | 为什么错 |
|---|---|
| Results 里夹杂大量**已发表的（带文献的）数据** | 那是 Discussion 的内容 |
| Results 里出现机制解释（"这说明…"） | 那是 Discussion 的内容 |

> 只有当你**对比自己数据与文献数据**时才引，且只引被比较的那篇。

## 🔴 图表硬参数（技术检查卡口）

| 项 | 要求 |
|---|---|
| 格式 | TIFF / JPG |
| **分辨率** | 🔴 **300 dpi 至少** |
| 单图 / 总文件 | 🔴 **<10 MB / <50 MB** |
| 图中字体 | Arial、Helvetica、Times New Roman |
| 图宽度（双栏刊） | 单栏 **<85 mm** / 双栏 **<180 mm** |
| 线条粗细 | **0.25 与 0.5 mm 组合** |
| 字号 | **10&6** 或 **12&8** 组合；🔴 严禁 <4 号，不推荐 >12 号 |
| 图注 | 🔴 **只看图注就能把图看明白** |
| 表名 | **写在表上** |
| 编号 | 图按**文中出现顺序**编号，图文件按顺序命名 |

### 🔴🔴 Word 缩放铁律
> **从制图 → 导出 → 最后插入 Word，全程严禁拉对角线或等比例缩放！**
> 会破坏图元比例与分辨率。Word 里插图表，禁止拉对角线缩放。
