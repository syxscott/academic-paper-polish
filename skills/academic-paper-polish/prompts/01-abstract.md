# 模块 1 · 摘要润色（Abstract）

> 适用：写完 / 改完正文后回头写摘要，或按目标期刊要求压缩摘要。

```text
请根据我提供的论文摘要初稿进行优化与重构，确保摘要能精炼概括研究的核心贡献，并遵循学术规范。

- **研究背景**：用一至两句话凝练介绍本研究的宏观领域背景与具体研究问题，明确指出当前存在的研究缺口。
- **研究方法**：清晰、准确阐述核心方法、关键技术或理论框架。避免晦涩术语，确保简洁与精确。
- **核心发现**：客观突出最关键的实验结果或理论发现。用精确数据或定性结论支撑，并强调其重要性。
- **意义与影响**：凝练总结本研究的理论贡献和/或实践价值，阐明其对学术界或相关行业的潜在影响。
- **语言风格**：采用正式、客观的学术语言，避免口语化和主观陈述。修正语法、拼写及标点错误。

请处理以下摘要内容：【此处粘贴你的摘要初稿】
```

## 评审维度速查

| 维度 | 检查点 |
|---|---|
| 研究背景 | 宏观背景 + 具体问题 + 研究缺口 |
| 研究方法 | 核心方法 / 关键技术 / 理论框架 |
| 核心发现 | 精确数据 + 定性结论 |
| 意义与影响 | 理论贡献 + 实践价值 |
| 语言风格 | 正式、客观、无口语 |

## 地学 / SCI 期刊补充约束

- **结构**：背景 → 科学问题 → 研究结果 → 研究意义
- **分层指示词**：*"However / yet…"* 表科学问题｜*"We found that… / The results show that…"* 表结果｜*"Based on…, we suggest that…"* 表讨论
- 🔴 **自明性**：避免引用文献、图表、缩写；避免化学结构式、数学表达式、角标、希腊文
- 🔴 **不得出现参考文献**
- 🔴 **摘要语法错误 ≤ 6 处** —— 编辑原话：*"if there are more than 6 grammatical errors in the abstract, then I don't waste my time carefully reading the rest."*（ES&T 编辑）
- **篇幅**：约 300 词（部分期刊）；ES&T 研究论文限 7000 词
