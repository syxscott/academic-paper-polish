## Review dimensions

| Dimension | Check |
|---|---|
| Background | Broad context + specific question + stated gap |
| Methods | Core method / key technique / theoretical framework |
| Main findings | Precise data + qualitative statement |
| Significance | Theoretical contribution + practical value |
| Language | Formal, objective, no colloquialisms |

## Journal constraints to apply

- **Structure**: background → research question → results → significance
- **Signposting**: *"However / yet…"* signals the problem; *"We found that… / The results show that…"* signals results; *"Based on…, we suggest that…"* signals interpretation
- 🔴 **Self-contained**: no citations, no figures/tables, no undefined abbreviations; no chemical formulae, equations, subscripts, or Greek letters unless unavoidable
- 🔴 **No references in the abstract** (exception: PNAS requires any abstract citation to be given in full inside the abstract *and* in the text)
- 🔴 **Length** (varies by journal — check before you start):

| Journal | Abstract limit | Special front-matter requirement |
|---|---|---|
| *Earth-Science Reviews* / *Palaeoworld* | **250 words** | *ESR*: must be a **single paragraph** |
| *Nature* | **200 words** (called a **summary paragraph**) | Four-part structure; no numbers, abbreviations, or units |
| *PNAS* | **250 words** | **Significance Statement ≤120 words** (Direct/Contributed only) |
| *Paleobiology* | **300 words** | **Non-technical Summary ≤300 words** |
| *Acta Palaeontologica Polonica* | **100–300 words**, structured | New taxa must be named in the abstract |
| *Palaeontologia Electronica* | **250 words** | **Plain language summary** required |

> ⚠️ These front-matter requirements are **not interchangeable**. Switching journals means rewriting the front matter, not reusing it.

## The four-part Nature summary paragraph

1. 2–3 sentences of basic-level introduction to the field
2. A brief account of the background and rationale
3. The main conclusions, introduced by *"Here we show"* or an equivalent
4. 2–3 sentences placing the findings in a broader context so readers outside the field see how the field moved forward
