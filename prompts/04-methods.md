# 模块 4 · 研究方法润色（Methods）

> 适用：材料与方法 / 数据与方法 / 实验设计章节。核心判据：**读者看完能重复你的实验**。

```text
请审查并优化我提供的研究方法章节，确保其描述具备严谨性、清晰度和可复现性。

- **研究设计**：检查是否明确说明了研究类型（如实验、调查、案例研究、元分析等）及其适用性依据——即为什么该设计能有效回答研究问题。
- **数据采集/处理**：检查是否逐一说明了以下要素：①数据来源（数据库名称/采集平台/实验环境）；②样本量及纳入/排除标准；③采集时间范围；④缺失值处理方法及理由。任何一项缺失请明确指出并要求补充。
- **模型/算法描述**：对于核心模型或算法，检查数学表达是否规范，关键假设是否明确列出，实现细节（如超参数设置、训练/测试划分、软硬件平台）是否充分到足以让他人复现。
- **评估指标**：审查所选评估指标是否与研究目标高度相关，其定义和计算公式是否清晰无误。若指标选择存在更优替代方案，请提出建议并说明理由。

请处理以下研究方法内容：【此处粘贴你的研究方法初稿】
```

## 🔴 地学 / 实验科学补充

### 四段式模式
1. 客观描述**区域地质背景、气候背景、环境参数**
2. **样品采样方法、样品数量**
3. 本研究所采用的**实验方法、仪器检测条件、软件版本**
4. 🔴 **重点：让读者看完知道如何开展、如何重现实验**

### 自查（缺任一项即不合格）
- [ ] 研究/实验设计 + 适用性依据（为什么这个设计能回答这个问题）
- [ ] 采样点位 / 深度 / 坐标 / 时间
- [ ] 样品数量与保存条件
- [ ] 仪器型号 + 检测条件（温度、压力、pH、浓度、标定）
- [ ] 数据处理软件与版本
- [ ] 缺失值 / 异常值处理方法及理由

### 常见错误
- ❌ 缺少参考文献和标准流程（自创？没认可度）
- ❌ 缺少细节，别人**无法重复**

## 引文密度

**方法章节同样需要引用** —— 引用的是**标准流程与既有方法**，不是你的结果。

| 场景 | 是否引文 |
|---|---|
| 采用标准方法 | ✅ 引该方法的原始文献或标准 |
| 自创改进方法 | ✅ 引原始方法，说明改进点 |
| 常规操作（清洗、干燥） | 可不引，但需写清参数 |
| **你的实验结果** | ❌ 不引（属 Results） |

- 代码可用性：GitHub URL + DOI（Zenodo）
- 🔴 不可用时必须说明原因，而非沉默省略
