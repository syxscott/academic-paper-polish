# 模块 3 · 文献综述润色（Literature Review）

> 适用：独立文献综述章节，或学位论文的"国内外研究现状"。与模块 2 的区别：模块 2「快速引出缺口」，本模块「系统性梳理与批判」。

```text
请评估并提升我提供的文献综述章节的学术深度和质量。本模块的目标是系统性梳理现有研究，构建批判性、综合性的分析框架，与引言中的「快速引出缺口」形成区隔。

- **主题式整合**：检查文献综述是否围绕核心主题或关键变量组织，而非按作者或发表时间简单罗列。如非主题式结构，请提出重组建议，并示范如何按主题重新归类文献。
- **批判性分析**：识别出我仅停留在描述层面（「谁做了什么」「发现了什么」）的部分，在这些位置加入批判性分析：指出不同研究间的矛盾、方法论的局限性、理论预设的缺陷等。
- **建立对话关系**：评估综述是否将不同文献置于「对话」语境中——即明确指出研究之间的传承、辩驳或互补关系。帮助我强化文献间的内在逻辑联系，而非各自孤立地介绍。
- **凝练研究缺口**：在综述结尾，帮助我更清晰、更有力地总结现有研究的集体不足（而非个别文献的缺陷），从而自然地、逻辑严密地引出本研究的切入点。

请处理以下文献综述内容：【此处粘贴你的文献综述初稿】
```

## 🔴 综述论文（Review Article）的结构

与研究论文不同，综述有自己的骨架：

```
Title → Author → Abstract → Introduction
  → Summary of major issues in the study field
  → Model and discussion
  → Perspective on future study
→ Acknowledgement → References → Figure and table caption
```

### 三类文体对比

| 维度 | **Review paper** | **Research paper** | **Perspective** |
|---|---|---|---|
| 内容 | 评价已发表文献 | 讨论作者当前的研究发现 | 提出展望/观点 |
| 数据 | 已有研究数据 | 新实验发现 | — |
| 篇幅 | 比研究论文长 | — | 受期刊限制 |

### 引言三段式（综述版）

| # | 要素 | 说明 |
|---|---|---|
| 1 | **Subject background** | 一般性话题，提供语境 |
| 2 | **"Problem"** | 趋势、新视角、缺口、冲突 |
| 3 | **Motivation / justification** | 作者综述的**理由 + 全文的方法和组织** |

**技术规格**：一般现在时（描述自己方法/结果用过去时）｜引用密度高｜**占正文核心部分 10%–20%**

## 🔴 小标题的六种组织标准

- methodological approaches（方法路径）
- models or theories（模型或理论）
- extent of support for a given thesis（对某一论点的支持程度）
- studies that agree vs. studies that disagree（正反对比）
- chronological order（时间顺序）
- geographical location（地理区域）

**分标题层级**：分得越细越好，**至少三级**，三级下还可能有四、五级标题。

**用问句作小标题** —— 信息量远高于"XX 研究现状"：
- *What's the principles and mechanisms controlling the yields of ·O₂⁻, H₂O₂ and ·OH from O₂ reduction by different types of reduced species?*
- *How abiotic and biotic mechanisms co-contribute to the production of different ROS?*

## 🔴 综述准备的 18 个步骤

**顺序反直觉：主体(11) → 结论(12) → 引言(13) → 摘要(14)**。引言和摘要在结构定稿后才写得出来。

| Stage | # | Step |
|---|---|---|
| prepare | 1 | Narrow the topic, define a few research questions or hypotheses |
| | 2 | Search literature sources, refine topic and questions during the search |
| | 3 | Read, evaluate, classify and make notes |
| | 4 | Redefine the focus and research questions, define the **take-home message** |
| develop structure | 5 | Compose a preliminary title |
| | 6 | Find a structuring principle (chronological / subject matter / procedure) |
| | 7 | Prepare an outline, find headings for the text body |
| write draft | 8 | Plan the content of each paragraph |
| | 9 | Prepare tables, concept maps, figures |
| | 10 | Draft the methods section (if needed) |
| | 11 | **Draft the body sections** |
| | 12 | Draft the conclusions |
| | 13 | **Draft the introduction** |
| revise | 14 | Draft the abstract |
| | 15 | Revise sections, abstract & title, tables, figures & legends |
| | 16 | Revise citations and references |
| | 17 | Correct grammar, spelling, punctuation |
| | 18 | Adjust the layout |

## 🔴 参考文献要求

| 项 | 要求 |
|---|---|
| **数量** | 多数约 **100 篇**是衡量综述质量、水平的标志 |
| **时效** | 近 5 年，最好近 1–3 年 |
| **来源** | 优先核心期刊、一次文献、权威学者 |
| **禁止** | 不引非公开发表文献、教材、专科书内容 |

**五个引用误区（必查）**

| # | 误区 | 表现 |
|---|---|---|
| 1 | **知而不引** | 借鉴了同行工作却故意不引用，让自己工作显得"新颖" |
| 2 | **断章取义** | 故意截取作者试图否定的部分来烘托自己观点 |
| 3 | **引而不确** | 没认真看原文，引文错漏 |
| 4 | **来源不实** | 来源不可靠且不注明；常见于统计数字 |
| 5 | **盲目自引** | 非为说明与前期工作的关系，纯粹为提高被引次数 |
