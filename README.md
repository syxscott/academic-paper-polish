# 论文初稿全流程润色指令合集（paper-polish-prompts）

一套覆盖论文全章节的学术润色 prompt 模板，按写作顺序使用八个模块即可完成从初稿到终稿的全流程优化。

## 适用场景

- 学术论文（期刊投稿、学位论文、会议论文）各章节的初稿润色与重构
- 综述类文章的学术化改写
- 降低 AI 生成痕迹，使文本更接近真人学术写作

## 八个模块

| 顺序 | 模块             | 用途                                                       |
| ---- | ---------------- | ---------------------------------------------------------- |
| 1    | 摘要润色         | 精炼研究背景、方法、发现与意义                             |
| 2    | 引言润色         | 倒三角结构、缺口论证、研究问题、章节预告                   |
| 3    | 文献综述润色     | 主题式整合、批判性分析、文献对话、研究缺口                 |
| 4    | 研究方法润色     | 设计、数据、模型、评估指标的可复现性                       |
| 5    | 结果润色         | 客观陈述、逻辑结构、图表规范                               |
| 6    | 讨论润色         | 结果解读、文献对话、理论贡献、实践启示、局限与展望         |
| 7    | 结论润色         | 核心回顾、贡献重申、避免新信息、宏大愿景                   |
| 8    | 降低 AI 率       | 终稿通篇去 AI 化润色                                       |

## 推荐使用顺序

```
摘要 → 引言 → 文献综述 → 研究方法 → 结果 → 讨论 → 结论 → 降低 AI 率
```

第八模块「降低 AI 率」是终稿通篇润色，必须在前七章全部定稿后再使用。

## 作为 AI Agent Skill 使用

本仓库以通用 Agent Skill 格式打包。`SKILL.md` 顶部包含 YAML frontmatter，可直接放入支持 skill 调用的 AI 编辑器 / Agent 平台：

| 平台 / 工具         | 放置路径（示例）                                            |
| ------------------- | ----------------------------------------------------------- |
| Claude Code         | `~/.claude/skills/paper-polish-prompts/SKILL.md`            |
| Cursor              | `~/.cursor/rules/paper-polish-prompts.mdc`（需补 mdc 头）   |
| Trae / 其他通用    | 将 `SKILL.md` 整文件作为 system prompt 或规则文件载入      |

`SKILL.md` 的 `description` 字段已写明触发场景（用户提供学术论文某章节初稿并请求润色 / 优化 / 重构 / 降低 AI 率时调用），可直接被 skill 自动发现逻辑使用。

## 直接作为 Prompt 使用

将各模块 prompt 中的「【此处粘贴你的XXX初稿】」替换为对应章节内容，发给 AI 即可。

**示例（摘要润色）**：

```
请根据我提供的论文摘要初稿进行优化与重构 ...
请处理以下摘要内容：
【摘要初稿正文】
```

**示例（降低 AI 率 / 终稿）**：

```
请你作为一位经验丰富的学术编辑，对以下全文进行「去 AI 化」润色 ...
以下是我需要润色的原文：
【全文终稿】
```
