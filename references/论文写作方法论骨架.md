# 论文写作方法论骨架

> 面向地学 SCI 论文与学位论文的写作与投稿方法论。
> 讲的是「怎么想、怎么写、怎么投」；配合同目录的《格式硬参数与文献检索实操》使用，那份讲「怎么排、怎么查」。


---

## 一、总纲：论文写作前的四项准备

作者必须能回答 4 个问题：
1. **Why did you start?** 你为何做这些工作
2. **What did you do?** 你做了哪些工作
3. **What did you find?** 你发现了什么
4. **What does it mean?** 它的意义是什么

关键判断：
- **解决问题的高度和广度 → 决定能投哪些期刊**
- **结果和认识的可靠性 → 决定文章被接受的概率**

四项准备：
| # | 准备项 | 要点 |
|---|---|---|
| 1 | 确定主题思想和内容 | 回答上述 4 问；正名自己的科学意义 |
| 2 | 确定投稿期刊 | 内容是否符合期刊要求；**时效性**（初审/外审/录用周期）；**结构框架与写作要求**（结果与讨论是否分开）；格式要求（是否有独立结论部分） |
| 3 | 完成所有图件、表的制作 | 见 1.3 |
| 4 | 读刊的 Aims & Scope 与稿约 | 见 1.4 |

### 1.3 制图要求

- 软件：Origin Lab、Adobe Illustrator / CorelDRAW、Matlab、R 语言
- **图件要美观、易读 —— 配色很关键**

### 1.4 实例对照：读刊的 Aims & Scope 与稿约
| 期刊 | 要点 |
|---|---|
| ES&T | Research Article 限 **7,000 词**；栏目制（Biogeochemical Cycling、Data Science、Occurrence Fate…）；结构含 Abbreviations、Formulae and Equations |
| Water Research | 开放获取，IWA 合作刊；聚焦 anthropogenic water cycle / water quality |
| GCA | **不发表纯方法学/技术/模型类论文**，须有 broader geochemical significance；**不发表 regional case studies** |

## 二、写作姿态

盖房子比喻：
1. **搭框架** — 与导师充分讨论后确定，避免大返工（= 设计图 / 浇筑框架）
2. **持之以恒写初稿** — 最难、花时最长（= 搬砖砌墙）；每天写一点或集中一段时间
   - 写作时**保证连续输出**，拼写/语句/参考文献**写完一段/节后再整体改**
3. **修改** — 请**所有**合作者提意见（= 装修）
4. **整体完善** — 避免拼写、格式等低级错误（= 全屋清洁）

## 三、SCI 论文结构

```
Title / Authors / Abstract / Keywords      → 需准确且利于检索
Main text (IMRaD)
   Introduction
   Methods
   Results
   Discussion (Conclusion)                  → 各部分功能不同
Acknowledgements / References / Supplementary material
```

## 四、题目

- 准确、简洁、清楚；长度/缩写/大小写参照目标期刊作者指南 + 该刊近期论文
- **核心内容的关键词尽量放开头**
- 评论性题目可用问句增加吸引力
  - 范例：*When is a bird not a bird?* Nature, 1998, 393:729–730
- **改题实例**：
  - 改前：Enhanced Electron-Accepting Capacity of Natural Organic Matter during Its Interaction with Fe Oxyhydroxides
  - 改后：Asymmetrical changes of electron-donating and electron-accepting capacities of natural organic matter during its interaction with Fe oxyhydroxides
  - 启示：改后同时点出"给体/受体不对称变化"两条线索，比"提升"更准确、更学术

## 五、署名

| 项 | 规则 |
|---|---|
| 总原则 | 按实际贡献大小定署名；每位作者都要对论点、数据、结果负责；责任作者须有答辩能力与义务。**贡献很少者放致谢，不进署名** |
| 通信作者 | 课题总负责人，负责与编辑部一切通信、经费/设计/把关、可靠性责任；好处是能与外界建立更广联系（受邀审稿、写综述，提升学界地位） |
| 第一作者 | 贡献最大者；拥有最多最重要的图表 + 初稿撰写人 |
| 共同一作 | 地位相同时用 "joint first author"，并注明 *These authors contributed equally to the work* |
| 地址标署 5 条 | ① 详细通讯地址 + 邮政编码；② 多地址按作者出现顺序以上标标注；③ 出版时已调离 → 脚注 "Present address"；④ 兼聘/客座人员须**同时标注实际单位与受聘单位**，并明确有效通讯地址；⑤ 第一作者非通信作者时按期刊规定标注（多数用星号 *） |

实例：多单位上标 a–g + 通讯作者双星号。

## 六、摘要

- 摘要≠结论；"第一口苹果的品尝效果"
- **编辑/审稿人一般只花 15 分钟看摘要+引言**，第一印象不好就去找拒稿理由
- 摘要读者面远大于全文读者面

**三种类型**
| 类型 | 特点 |
|---|---|
| 指示性 / 说明性（indicative/descriptive） | 只概括主题、意义、展望，不涉论据和结论；帮读者决定是否读全文 |
| 报道性（informative） | 按 IMRaD 总结；**可部分取代阅读全文** |
| 结构性（structured） | 按期刊列出的小标题写；多用于医学类期刊 |

**撰写技巧**
- 结构：背景 → 科学问题 → 研究结果 → 研究意义
- 短句；用词为潜在读者所熟悉
- 用指示性词语分层：*"However…"* 表科学问题；*"We found that…/The results show that…"* 表结果；*"Based on…, we suggest that…"* 表讨论
- 保证**独立性/自明性**：避免引用文献、图表、缩写；避免化学结构式、数学表达式、角标、希腊文
- 可适当强调创新与重要之处，含主要论点和重要数据

## 七、引言★核心

### 7.1 四大内容
1. 综述研究背景 — 领域与理论基础，概述前人成果
2. 综述研究现状 — **由现状引出问题**
3. 问题剖析 — 这问题包含什么、解决思路
4. 目的与手段 — 用什么方法解决

### 7.2 背景写作要领
- 先"大盖帽"：大背景、大意义
- 逐渐聚焦：肯定前人贡献（"站在巨人肩膀上"）
- ⚠️ **重要**：以为多引他人工作会降低原创性，**实际效果常常相反**。不充分阐述背景、不引用相关重要文献，审稿人**至少会认为你阅读文献不够**

### 7.3 如何指出科学问题
- 前人尚未研究或处理不完善的重要课题
- 过去研究衍生出的新问题
- 前人提出两个以上互不相容的理论/观点，需进一步研究解决冲突
- 过去研究可自然扩展到新题目/领域，或原方法技术可改善扩展到新应用

### 7.4 措辞分寸
- ❌ 忌直接批评：*"The deficiency of Wang's approach is…"*、*"The problem of these papers…"*
- ✅ 绕开作者与文献：*"However, the mechanism has not been fully understood."*、*"None of the other phases have been examined in detail."*
- ✅ 顺序推进：强调最重要发现，让读者**顺序逻辑地演进阅读**
- ❌ **忌故意制造悬念**指望结尾高潮——读者没耐心读到最后一章
- ❌ 忌轻易用 *for the first time*；忌"首次提出/首次发现/达到国际先进水平"等评价式用语（每篇有 novelty 都可称"第一次"，"第一次"只应指较重要的进展）

### 7.5 引言结构 = 倒金字塔
由大到小逐步收拢，直至恰好处**提出本研究**。与 Discussion 一样需反复打磨。

**常犯错误** — 原文用三只"沙漏/漏斗"示意图（Figure 5.1: Matching the opening to the resolution）：
| 图形 | 英文原文 | 中文 | 读者反应 |
|---|---|---|---|
| A. 开口大于收口 | *Opening wider than resolution: overpromising* | 如果太泛、高调，最后解决的是窄小的问题 | 读者觉得被欺骗（*cheated*），不认可 |
| **B. 开口 = 收口** | ***On target. Your readers will be satisfied.*** | **针对目标** | **✅ 读者认可** |
| C. 收口大于开口 | *Resolution wider than opening: underpromising* | 解决问题 > 提出问题 | 读者根本看不到一个值得关注的 story，不认可 |

→ 核心即 **"opening（提出的问题）必须与 resolution（给出的答案）对齐"**。

### 7.6 实例：黄铁矿羟基自由基（GCA 172 (2016) 444–457，P33–36）

三层结构框架：
```
第一层次：硫铁矿（黄铁矿、马基诺矿、四方硫铁矿）
第二层次：分布特征 | 形成机理 | 氧化机理 | 环境效应 | 工程应用
第三层次：
  分布特征 → 海洋沉积物 / 河湖沉积物
  形成机理 → 微生物机制 / 非生物机制
  氧化机理 → 微生物机制 / 非生物机制
  环境效应 → 酸腐蚀效应 / 还原转化 / 氧化效应
  工程应用 → 铁矿物冶炼 / 污染修复
```

六段式行文：
| 段 | 内容 |
|---|---|
| 1 | 黄铁矿非生物氧化的环境效应 → 引出活性氧（ROS） |
| 2 | 深入介绍活性氧的环境效应 |
| 3–4 | 介绍现有机制认识，梳理问题 |
| 5 | **总结问题**（本文问题相对分散，所以需要总结梳理）— 列出 4 个未解问题 |
| 6 | 给出解决问题的思路和研究目的（3 个目标） |

### 7.7 引言常用句式
引出不足（用 However 引导）：
```
Previous research (studies, records) has (have) investigated / studied (with respect to)
  failed to consider / ignored / misinterpreted / neglected to
  overestimated, underestimated / misleading
thus, these previous results are inconclusive, misleading, unsatisfactory, questionable, controversial
Uncertainties (discrepancies) still exist ...
However, little information / little attention / little work / little data / little research
  or few studies / few investigations / few researchers / few attempts / none of these studies
has (have) been less focused on / attempted to / conducted
```

**强调自己研究重要性的 5 种切入**
| # | 切入 | 做法 |
|---|---|---|
| 1 | **时间问题** | 研究问题较新 → 大量提及较老问题的研究及重要性，再说 However 新时段研究不足 |
| 2 | **物性/研究手段** | 提出当前流行方法与物质性质，再说对自己所研究的方向方法研究甚少 |
| 3 | **研究区域** | 先总结相邻或其他区域研究，再强调本区域不足 |
| 4 | **不确定性** | 前人研究多但存在两种及以上观点，uncertainties / ambiguities 值得澄清 |
| 5 | **提出假设验证** | 完全无前人工作可比时，可自信提出假设，本文即证实 |
   - *We aim to test the feasibility (reliability) of the ...*
   - *It is hoped that the question will be resolved (fall away) with our proposed method (approach).*

## 八、材料与方法

模式较固定：
1. 客观描述区域地质背景、气候背景、环境参数
2. 样品采样方法、样品数量
3. 实验方法、仪器检测条件、软件使用情况
4. **重点：让读者看完知道如何开展、如何重现实验**

## 九、结果与讨论

### 9.1 期刊差异
| 期刊 | 立场 |
|---|---|
| **GCA** | Results 与 Discussion **必须分开**，各自独立编号；Results 只提供数据/观测，Discussion 整合解释、把新结果置于前人工作中、指出更广的地学意义与启示 |
| **ES&T** | Results and Discussion **合并**；Be complete but concise；**不使用独立结论段**，concluding statements 并入 R&D；避免无数据支撑的推测与冗长讨论 |

⚠️ 这正是 P4"先确定期刊"的原因——结构要求因刊而异。

### 9.2 结果陈述技巧

读完结果应让人感觉：这个实验条件确实有重要影响，且**关键影响因素是什么** —— 要引导读者跟着节奏走。

**Results 的层级组织范例**
```
3 Results
  3.1 OH production from pyrite oxidation
  3.2 H2O2 production from pyrite oxidation
  3.3 Fe2+ and SO4(2−) production from pyrite oxidation
  3.4 XRD, FSEM-EDS and XPS
  3.5 Oxidation of As(III) and sulfanilamide in anoxic and oxic pyrite suspensions
4 Discussion
  4.1 Mechanisms of OH production from anoxic oxidation of pyrite
  4.2 Mechanisms of OH production from oxic oxidation of pyrite
      4.2.1 H2O2 formation and decomposition
      4.2.2 Relative contributions of each pathway
      4.2.3 Summarized mechanisms for OH production under oxic conditions
  4.3 Environmental significance
```
→ 读法：**Results 按"产物/表征手段"平行铺开（3.1–3.5），Discussion 按"机理"收拢（4.1–4.3）**。同一批结果在两部分用不同坐标系重组。

### 9.3 讨论部分 6 步框架
1. 引言 — 提及过往研究空白 / 重申科学问题 / 目的
2. 重述主要发现 — 用数据/图说话
3. 解释结果 — 结果的指示意义；与其它论文比较，异同点、差异原因
4. 表明局限性 — 对结果的潜在影响
5. 对以后研究的启示 — 如何进一步探索
6. 结论 — 重温研究问题和研究结果

**实例基于结果的认知提炼关键因素，逐一讨论**
```
4 Discussion
  4.1 Mechanisms of OH production from pyrite oxidation by H2O2
      4.1.1 OH production from surface reaction
      4.1.2 OH production from aqueous reaction
      4.2 Relative contribution of surface versus aqueous reactions
      4.3 Environmental and geochemical implications
5 Conclusion
```

### 9.4 讨论常用动词
| 功能 | 动词 |
|---|---|
| 陈述论点/观点 | suggest, report, present, expect, describe |
| 说明论证 | support, provide, indicate, identify, find, demonstrate, confirm, clarify |
| 推荐建议 | suggest, suggestation, recommend, recommendation, propose, necessity, necessary, expect |

### 9.5 环境/地学意义
前言+方法+结果讨论写完后，读者知道"做了什么、解决了什么问题"，但**意犹未尽——知道了这些有什么用？** 这一节回答环境/地学意义，常作为 Discussion 的 4.3 之类的独立小节。

## 十、结论

**两条要点**
1. **总结要点、突出亮点** — 从大的层面总结研究意义；突出创新点
2. **指明方向** — 不只写"做了什么、发现什么"，应指出理论意义/实际意义（implication）、将来应采取什么行动；即指明**局限性 + 尚未解决的问题 + 今后方向**

**Do**
- Summarise your overall findings
- Provide a synthesis of key points
- Highlight the important takeaways
- Point out the problems and questions remaining
- Indicate future directions
- **End with a strong, final sentence**

**Don't**
- Repeat background from the Introduction
- Present new arguments or evidence
- Draw conclusions not supported by your data
- Be abrupt and leave a reader hanging

**实例 A结论两段式**：① 本研究做了啥 + 主要发现点和原理（无氧条件下 ·OH 主要由 H₂O(ad) 表面硫缺陷氧化生成，增大比表面积会提高 ·OH 产率；有氧条件下 ·OH 主要由 O₂ 还原生成，次要来自表面硫缺陷和 Fe²⁺/硫中间体，H₂O₂ 为主要中间体经 Fe²⁺ Fenton 分解）；② 影响有机污染物与氧化还原活性元素的命运，尤其在流动环境。

**实例 B★ 局限性 + 未来方向的完整写法**
> 结论段以 *"Despite its advantages, the modified chemical probe method also has some limitations"* 转折，随后用 **First… Second… Further research should…** 逐条列出：
> 1. **First** — 只能在 −0.4 V vs SHE 测 EAC、0.7 V vs SHE 测 EDC（受限于缺乏合适化学探针）
> 2. **Second** — 氧化条件下化学探针本身可变异性大 → 不适合**野外测量**
> 3. **Further research should focus on** — 识别合适化学探针 + 开发可支持可靠野外测量的装置

→ 可直接套用的句式骨架：`尽管有优势，方法仍有局限：First… Second… Further research should focus on…`

## 十一、参考文献

### 11.1 四原则
**全面** — 研究背景文献、方法参考、支持**或冲突性**证据的文献、供论据比较的文献
**精选** — 最好是近年的；**一定要引 Science、Nature、Annual Reviews 系列**等近期文献以增强立论权威性
**尽量阅读原文**
**仔细核对，书写规范**

### 11.2 五个引用误区★自检清单
| # | 误区 | 表现 |
|---|---|---|
| 1 | **知而不引** | 借鉴了同行类似工作却故意不引用，让自己工作显得"新颖""领先" |
| 2 | **断章取义** | 故意截取作者试图否定的部分来烘托自己观点 |
| 3 | **引而不确** | 没认真看原文，引文错漏 |
| 4 | **来源不实** | 字句来源不可靠（非正式/非学术出版物）且不注明来源；常见于统计数字 |
| 5 | **盲目自引** | 非为说明与前期工作的关系，纯粹为提高被引次数 |

### 11.3 管理
用文献管理器：Zotero、EndNote。三个好处：建自己的知识文献库；**保证引文与参考文献一致**；统一改格式，换投期刊很方便。

### 11.4 综述论文的文献要求
- 参考文献**不能省略**；**数量（多数 100 篇左右）是衡量综述质量、水平的标志**
- 为读者提供寻找原始论文的线索；也是对原著作者劳动的尊重
- 引用六原则：① 亲自阅读的最新最有价值原著；② 尽量核心期刊；③ **尽量引用一次文献**；④ 权威知名学者；⑤ **近 5 年，最好近 1–3 年**；⑥ 不引非公开发表文献、教材、专科书内容

## 十三、投稿与返修

### 13.1 语言与"什么让你被接收"

上下标、字体大小、参考文献前后一致、格式统一。

**★ What gets you accepted?**
> **A**ttention to details（注重细节）
> **C**heck and double check your work（反复核查）
> **C**onsider the reviews（重视审稿意见）
> **E**nglish must be as good as possible（英语尽可能好）
> **P**resentation is important（呈现很重要）
> **T**ake your time with revision（修改不急于求成）
> **A**cknowledge those who have helped you（致谢帮助过你的人）
> **N**ew, original and previously unpublished（新颖、原创、未曾发表）
> **C**ritically evaluate your own manuscript（批判性评估自己的稿件）
> **E**thical rules must be obeyed（必须遵守伦理规范）

（A–C–E–P–T–A–N–C–E 首字母连读即 "ACCEPTANCE"）

> **编辑原话**：*"[This] paper fell well below my threshold. I refuse to spend time trying to understand what the author is trying to say. Besides, I really want to send a message that they can't submit garbage to us... My rule of thumb is that if there are more than **6 grammatical errors in the abstract**, then I don't waste my time carefully reading the rest."*

→ 门槛线：**摘要语法错误 ≤ 6 处**。

### 13.2 审稿人推荐途径
国际期刊一般要作者提供 **3–5 位**相关审稿人：
- SCI 检索与你研究相关的科学家
- 文章的参考文献
- 相关期刊编委
- 学术会议主席/委员、相熟的专业人士

⚠️ **一般期刊论文不建议找领域大牛**；需认真自建期刊审稿人专家库。

### 13.3 审稿人关注什么★反向自查清单
1. 作者是否**合适地引用了自己的论文**，尤其密切相关的工作
2. 稿件论题是否**适合该期刊**
3. 内容是否**新颖、重要**
4. 论证是否合乎逻辑，讨论和结论是否合理
5. 参考文献引用是否妥当
6. 文字表达是否正确、简明、清楚
7. 实验描述是否清楚且**能被读者重复**、数据是否真实可靠
8. 图表使用和设计是否必要、规范、清楚

### 13.4 投稿信 Cover Letter
要点：**为什么我这篇稿子适合在贵刊发表**。

**GCA 的 Cover Letter 硬性要求**
1. 所有稿件**必须**附 Cover Letter
2. 说明本文如何契合该刊宗旨：*to present studies of fundamental significance and broad relevance for understanding geochemical systems, mechanisms, and processes, and of interest to a broad and diverse audience of geochemists*
3. 披露任何编辑应知晓的**潜在利益冲突（conflicts of interest）**
4. 可提出回避特定审稿人/编辑的人选，但**在 GCA 此要求仅为建议性质（purely advisory），不具约束力**
5. ⚠️ **必须提供 3 位 Associate Editors 的姓名**（具备评估该稿件专长的副主编），名单见 GCA editorial board 页面

### 13.5 投稿后 6 个状态
| 状态 | 含义与时长 |
|---|---|
| 1. **Submitted to Journal** | 刚提交，等待编辑部初审与分配审稿人；通常较快 |
| 2. **With editor** | 编辑分配稿件编号，初步审核决定是否送外审；风格不符直接拒稿。**几天到几周** |
| 3. **Under Review / Peer Review** | 审稿人评审。**几周到几个月不等，最耗时** |
| 4. **Decision in Process** | 编辑结合外审意见决定去留，通讯作者收到 Decision letter；状态跳转为 revise / accepted / reject。通常较快 |
| 5. **Revise** | 返修，重新送审。分大修（Major）小修（Minor），时限不同 |
| 6. **Accepted / Rejected** | 接受 → 进入出版流程；拒稿 |

### 13.6 SCI 的命运
**一、编辑直接拒稿（Deskmill / 出师未捷身先死）** — 常见格式化拒绝话术：
1. *"We regret to say that..."*
2. *"We suggest that you might submit it to another journal"*
3. *"An increasing volume of submissions prevents us from publishing all worthwhile manuscripts we receive. Competition for space in our journal has increased sharply in recent months."*
（编辑一开始说得再好也没用，他们已选定刊物）

**二、送外审后** — peer-review 刊物主要看审稿人意见：
| 结果 | 概率与含义 |
|---|---|
| **Rejected** | 很多期刊审稿人中有一个拒稿，编辑就拒稿 |
| **Major revision** | 发表有难度，需大改后重新送审；改好了基本可接收，不达标很可能被拒 |
| **Minor revision** | 都是小问题，完善即可，**基本等于 accept** |
| **Accepted** | 直接接收比较少见，一般都会有些修改意见 |

### 13.7 回复审稿人★六条
1. **所有问题必须逐条回答**
2. 尽量满足意见中需要补充的实验
3. 满足不了的也**不要回避**，说明不能做的合理理由
4. 审稿人推荐的文献**一定要引用**，并讨论透彻
5. 从审稿人角度理解并回答；拒绝修改意见要有理有据，**尽量不要与审稿人硬扛**
6. 感谢编辑和审稿人

**回复范例** — 审稿人质疑 "N2 吹扫可能除不掉全部 O2，建议提供处理后溶解氧数据"：
```
→ Thanks for this concern. As suggested, we supplemented the experiments to monitor
  the variation of dissolved O2 concentration during N2 purging. Measurement showed
  that the concentration of dissolved O2 rapidly decreased to 0.27 mg/L within 10 min
  and then slowly decreased to around 0.1 mg/L (Fig. R1).
→ To address the reviewer's concern, the original statement "the solution was purged by
  N2 (99.999%) for at least 30 min to remove O2" was revised to "the solution was
  purged by N2 (99.999%) for at least 30 min to reduce the dissolved O2 concentration
  to below 0.1 mg/L (Fig. S5)." (Lines 193–195)
→ In addition, the Fig. R1 was copied as Fig. S5 in the revised supporting information.
```
要素拆解：**感谢 → 补做实验给数据 → 指出原文哪一行(Lines)改成了什么 → 附加材料编号对应**。

## 十四、文献综述写作专题★课程重点

### 14.1 综述是什么
在**广泛阅读和理解某研究领域近期公开发表文献**的基础上：
1. 对研究成果的**提炼、综合和思考** — 学术观点和理论方法的整理
2. **阐明研究进展** — 对现有文献进行评价和分析
3. **揭示发展趋势** — 对未来提出建议或展望

> *A review article tells us about:*
> *— Recent major advances and discoveries in a field*
> *— Current consensus and debate*
> *— Significant gaps in this research area*
> *— The next research step in this field*

### 14.2 地学主要综述期刊
| 期刊 | 出版方 | 备注 |
|---|---|---|
| **Earth-Science Reviews** | Elsevier | 地学综述老牌顶刊 |
| **Annual Review of Earth and Planetary Sciences (AREPS)** | Annual Reviews | 每年一卷；仅约 20 篇；需邀请 |
| **National Science Review (NSR)** | Science Press / OUP | 中国 Science 系列，刊发综述 |

### 14.3 三类文体对比
| 维度 | **Review paper** | **Research paper** | **Perspective** |
|---|---|---|---|
| Content | Evaluates previously published literatures on a specific topic（评价已发表文献） | Discusses the present research findings of an author（讨论作者当前的研究发现） | 提出展望/观点 |
| 数据 | Existing research data | New experimental findings | — |
| Length | 比研究论文长 | — | — |
| 限制 | 受目标期刊篇幅限制 | — | 受目标期刊限制 |

### 14.4 两类综述作者
1. **已在一方向研究并有实质进展的学者** → 总结并指出新研究方向
2. **在新项目启动前做过文献综述的学者** → 从综述中发展出理论模型

### 14.5 两种综述类型
| 类型 | 特征 |
|---|---|
| **成熟主题**（Mature topic） | 已积累大量研究，需分析与综合 → **详尽文献回顾 + 概念模型**（conceptual model）综合并拓展已有研究 |
| **新兴议题**（Emerging issue） | 需曝光度 → 通常较短 |

两者共同要素：**progress + literature review → 指示新研究方向；Conceptual models**

**范例 B：Earth-Science Reviews 270 (2025) 105230**
- 配图 (a)：ROS production mechanism — **Abiotic vs Biotic mechanism** 双线 + **Geochemical condition** 调节，外围标注 **ROS type / ROS yield / O₂ / H₂O₂**，右侧 **Guidelines for evaluating ROS production**
- 配图 (b)：**Subsurface Zone** 分带示意 — 深层区（还原条件）→ 河流/过渡区 → Coastal Zone（潮汐、生物扰动、氧化还原交替），标注田块、沉积物、生物膜、Fe(II)/Fe(III)、Sulfide minerals
- 另一配图：Oxic-Biotic / Anoxic-Abiotic 两组界面机制对比（异养细菌竞争 O₂、有机质还原产物提供电子；Fe(II)/Fe(III) 循环）

### 14.6 如何收集文献
题目确定后，最要紧是查**最近的进展性资料**，使综述有先进性和系统性。两种方法：
1. **滚雪球法** — 找内容较完整的新文章，按其参考文献去收集原始资料。⚠️ **容易遗漏某一方面的文献**
2. **检索工具** — 文摘和索引类期刊，能较快找到。**（演示 Connected Papers）**

**阅读策略**：先浏览 → 再分类阅读。有的通读、细读，个别精读。**在科研浮躁、学术不端背景下，高水平（高影响因子）期刊、大专家著作的原文真实性可信度相对大；不出名的期刊和职称期刊注水量太大**。
→ 阅读时**摘记每篇的主要内容**：技术方法、重要数据、主要结果和观点，为写作做准备。

### 14.7 文献加工★四步
1. **筛选** — 从所收集资料中确定出与主题密切相关者
2. **鉴别** — 去伪存真
3. **分类** — 使资料内容单元化，从大到小逐层逐级划分
4. **归纳** — 使资料内容系统化并产生初步判断

> 合理的文献加工整理，是撰写综述的**关键一步**。

### 14.8 文章架构 · 三个作用
- 一部分综合他人工作，**另一部分论述自己的观点**
- 通过对"大是大非"的把握 → 发现新问题/新优点或缺点 → 提出改进方法 → 对未来工作的建议设想
- 更高层面：跳出实验细枝末节，从**原理、方法论和系统性**上加以评价
- ⚠️ 但论述越多，耗费时间精力越大；多数综述"综而不述"，读者看完对过去了解、对未来仍茫然

**动笔条件**：阅读完成能达到"大是大非"的境界 → 即可提笔。
**写作原则**：先搭框架，分门别类，不断细分。**分得越细越好，至少三级**，三级标题下还可能有四、五级标题。

### 14.9 搭框架的三个好处
| 做法 | 理由 |
|---|---|
| **a) 框定问题、缩小范围** | 避免"随兴所至"偏离方向失掉重点；分清主次而非眉毛胡子一把抓。综述不是写书，没有篇幅全面展论 |
| **b) 分解写作任务、减小压力** | "写 ≥5000 字 + 读 100 篇"会压力倍增且不知从何下手；细分后只需讨论某方法的某个参数 = 一个小段落，可立即完成 |
| **c) 有条不紊** | 像 TO-DO LIST，完成一项划去一项，进度直观 |

### 14.10 三种行文方式
| 写法 | 描述 | 适用 |
|---|---|---|
| **纵式** | 按时间先后或发展层次，对历史演变、目前状况、趋向预测作纵向描述，勾划来龙去脉和发展轨迹 | 要脉络分明：各阶段发展动态扼要描述，已解决什么、取得什么进展、还有什么问题、今后趋势如何；**文字描述要紧密衔接** |
| **横式** | 对国内外各方面（各种方法、各自成就观点）加以描述和比较。横向对比可分辨各种观点/见解/方法/成果的优劣利弊，又可看出不同层次的水平及差别 | **成就性综述** |
| **纵横结合** | 同时采用。例如写历史背景用纵式，写目前状况用横式 | 通过"纵""横"广泛综合文献资料，全面系统认识专题及方向，**作出比较可靠的趋向预测，为新研究选择突破口或提供参考依据** |

### 14.11 Review article 文章结构
```
Title → Author → Abstract → Introduction
  → Summary of major issues in the study field
  → Model and discussion
  → Perspective on future study
→ Acknowledgement → References → Figure and table caption
```

### 14.12 Perspective 范例解析
实例：*A critical review of mineral–microbe interaction and co-evolution: mechanisms and applications*, National Science Review, 9(10), Oct 2022, nwac128, DOI 10.1093/nsr/nwac128

| 章节 | 对应功能 |
|---|---|
| ROLE OF MINERALS IN AFFECTING MICROBIAL ACTIVITY<br>ROLE OF MICROBIAL ACTIVITY IN MINERALIZATION | **Summary** |
| MINERAL–MICROBE CO-EVOLUTION<br>APPLICATIONS OF MINERAL–MICROBE INTERACTIONS | **Discussion** |
| CHALLENGES AND FUTURE RESEARCH OPPORTUNITIES | **Perspective** |

### 14.13 前言（Introduction）写作
**内容**：提出问题、综述问题的现状和发展动态、有关概念和定义、**选择这一专题的目的和动机、应用价值和实践意义**。

**三段式要素**
1. **Subject background** — 一般性话题/关注领域，提供语境
2. **"Problem"** — 趋势、新视角、缺口、冲突，或单一问题
3. **Motivation / justification** — 作者综述文献的理由、文本的方法和组织

**技术指标**
- **Tense**: 一般现在时（**描述自己的方法和结果时用过去时**）
- **Citations**: Many（大量）
- **Length**: 占正文核心部分（引言、主体、结论）的 **10%–20%**

**范例解析**
- P85 上半：介绍 ROS（活性氧）的定义、来源、重要性 → 标注"**背景**"
- P85 下半至 P86 上半：沉积物/地下水的 ROS 研究进展、微生物机制、亚氧化还原动态 → 标注"**问题**"（指出认识缺口）
- P86 右栏：以 *"As ROS in the subsurface are a relatively new research frontier, the following questions remain unanswered: (1)...(5)..."* 列出 **5 个未解问题**，再接 *"In this review, we first summarize recent progress... In order to advance the development of this new research frontier, we further provide i) guidelines for evaluating..., ii) the..."* → 标注"**本综述拟解决的问题**"

### 14.14 主体（Summary + Discussion）写作
**主体 = 论据和论证**。通过提出问题、分析和解决问题，比较各种观点的异同点及其理论根据，从而反映作者的见解。**一般分为若干小标题分述。**

**小标题（subheadings）的组织标准**
- methodological approaches（方法路径）
- models or theories（模型或理论）
- extent of support for a given thesis（对某一论点的支持程度）
- studies that agree vs. studies that disagree（支持与反对对比）
- chronological order（时间顺序）
- geographical location（地理区域）

**主体应含三方面**
1. **历史发展**（简要描述）、**现状分析**（国内外研究现状及各派观点，**包括作者本人观点**）、**趋向预测**
2. 归纳整理的科学事实和资料进行排列和必要分析；对有**创造性和发展前途**的理论或假说要详细介绍并引出论据
3. 对**有争论的问题**介绍各家观点或学说进行比较；指出问题焦点和可能发展趋势并提出自己看法；在纵横对比中肯定研究水平、存在问题、不同观点，提出**展望性意见**
4. 最后概括重点评议，提出结论，**最好提出自己见解**，明确赞成什么、反对什么，指出今后科研方向和要解决的问题

### 14.15 研究展望（Perspectives）写作范例
> 写法：先给总体判断（general framework 已形成，但机理理解仍需方法学与基础理论双重推进），再 *"we propose the following six areas of particular research needs"*，分条展开。

范例（*Earth-Science Reviews* 2025, ROS in subsurface）6.1 Fundamental Mechanisms of ROS Production 之下的问句式小标题：
1. *What's the principles and mechanisms controlling the yields of ·O₂⁻, H₂O₂ and ·OH from O₂ reduction by different types of reduced species?*
2. *How abiotic and biotic mechanisms co-contribute to the production of different ROS, and how the interplay between abiotic and biotic mechanisms can be quantified?*
3. *Whether and how the electrons in separate subsurface zones can be transferred to O₂ for ROS production?*

→ 可直接套用的句式：**以一个具体问句作为小标题**，比"XX 研究现状"信息量大得多。

### 14.16 写作小细节★实操
- **连贯性**：写作最好一气呵成，不要写 A 时思考 B。
  - 写 A 时发现对 B 有用的材料 → 继续写 A
  - 写 A 时发现 B 存在的错误、疏漏 → **不要停下来，用便签备注**，继续写 A，回头再整理 B
- **二次文献（secondary citation）**：为论证一个结论，需引用文章主题之外的文献，或需从文献引用的文献里去找论据。
  → **对文献中引用他人的数据有必要去查证，避免错引文献和错引数据。**

### 14.17 用图来总结
范例：ROS 产生机制总览图 —— 中心为 ROS production 循环（O₂ reduction ↔ H₂O oxidation，含各步标准电位），四周环绕不同驱动途径：
- (a) ROS production from O₂ reduction：NOM（氧化态/还原态）、Fe(II)/Fe(III)、异养细菌 NADH/NADPH
- (b) ROS production from the oxidation of H₂O：石英表面 Si≡SiO⁻ 与 H₂O 反应、硫化物矿物表面 Fe²⁺–H₂O、电离辐射辐解 H₂O₂
- 右下：液滴凝结/蒸发界面上的 ROS

→ 意即：**用一张机制总览图代替大段文字**，是综述"高信息密度"的手段。

### 14.18 综述准备的 18 个步骤★最重要总表

| Stage | # | Step |
|---|---|---|
| **prepare** | 1 | Narrow the topic, define a few research questions or hypotheses（**收窄题目，定义少量研究问题或假设**） |
| | 2 | Search for literature sources, refine topic and research questions during the search（检索中**持续精炼题目与问题**） |
| | 3 | Read, evaluate, classify and make notes（读、评、分类、做笔记） |
| | 4 | Redefine the focus and the research questions, define the take-home message（**再定义焦点与研究问题，确定 take-home message**） |
| **develop structure** | 5 | Compose a preliminary title |
| | 6 | Find a structuring principle for article (e.g. chronological, subject matter, experimental procedure)（**找结构化原则**） |
| | 7 | Prepare an outline, find headings for the sections in the text body（拟大纲、定各级标题） |
| | **write draft** | 8 | Plan the content of each paragraph in the different sections（**逐段规划内容**） |
| | 9 | Prepare tables, concept maps, figures（**准备表、概念图、插图**） |
| | 10 | Draft the methods section (if needed) |
| | 11 | Draft the body sections（**先写主体**） |
| | 12 | Draft the conclusions |
| | 13 | Draft the introduction（**最后写引言**） |
| **revise** | 14 | Draft the abstract（在 revise 阶段写摘要） |
| | 15 | Revise drafts of different sections, abstract & title, tables, figures & legends |
| | 16 | Revise citations and references |
| | 17 | Correct grammar, spelling, punctuation |
| | 18 | Adjust the layout |

> ⚠️ **顺序反直觉但关键**：**主体（11）→ 结论（12）→ 引言（13）→ 摘要（14）**。引言和摘要在结构与内容定稿后才写得出来。

## 十五、可直接执行的自查清单（综合）
