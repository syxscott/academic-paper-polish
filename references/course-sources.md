## 提取方法记录（复用价值）

该 PDF 是 PPT 型，**纯文本提取只覆盖约一半内容**（16,354 字符 / 94 页）。有效流程：

```python
import fitz
d = fitz.open(pdf)
# 1) 文本层
for i, p in enumerate(d):
    open(f'p{i+1:03d}.txt', 'w', encoding='utf-8').write(p.get_text())
# 2) 渲染全页
for i, p in enumerate(d):
    p.get_pixmap(dpi=110).save(f'pg{i+1:03d}.png')
```

**关键：必须按图像面积占比区分"装饰图"与"内容图"，否则会漏读或浪费时间**

```python
pa = p.rect.width * p.rect.height
tot = 0
for im in p.get_images(full=True):
    for r in p.get_image_rects(im[0]):
        tot += r.width * r.height
pct = tot / pa * 100
# pct ≈ 1.9%  → 每页同一条装饰红线，文本层已够
# pct >  8%   → 内容图，必须读图
```

本 PDF 分布极干净：装饰统一 1.9%，内容统一 34–70%，无中间值，**阈值 8% 即可干净区分**。

⚠️ **教训**：「渲染了全部 94 页图」≠「读了 94 页图」。首轮实际只读 25 页，且漏掉的恰好是内容最密的页（P57 ACCEPTANCE 十点、P61 GCA Cover Letter 要求整页丢失）。**交付前必须用脚本做差集核算**：`未读页 ∩ 内容图页 = ∅`。

# 二、田力两份 PPTX 的提取与 v2 审计（2026-10-17）

**来源**：《论文写作规范与技巧-20250908-课件.pptx》43 页 + 《文献综述-20250908.pptx》35 页（田力，中国地质大学，2025-09-08）。整理稿见课程目录 `写作规范与文献检索_田力课件_精华整理.md`（v2，26 节）。

## PPTX 与 PDF 的方法差异
- PPTX 用 `python-pptx` 逐 shape 统计：`shape_type == 13`（PICTURE），`img% = Σ(w×h)/版面面积`
- 渲染用 slidep：`slidep screenshot <file.pptx> --page-index <0-based> --out x.png`
  🔴 参数是**位置参数 + `--page-index/--out`**，不是 `--file/--pageIndex/--output`——参数名写错时 exit 0 但**什么都不产出**
- 🔴 PPTX 的"装饰图"不是细线而是**整页模板照片**：大量页面 img≈36–38% 且 n_img=1，这类页文本层虽完整，但图内常是 **Guide for Authors 官网截图**（英文规范细节只在图里）——必须读，不能凭"有文本层"跳过

## v2 审计发现（第一轮"45 张全读"是错的）

## 审计方法论（写进流程）
1. **两遍计数**：渲染前先跑 shape 统计确定内容图全集；渲染清单 = 全集
2. **差集核算**：`未读页 ∩ 内容图页 = ∅` 才算完，不要用 `txt<100` 之类辅助条件缩小集合
3. **渲染自证**：渲染后必须 `ls` 确认文件数增加；exit 0 ≠ 成功产出
