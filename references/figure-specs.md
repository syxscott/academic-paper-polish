# 图表硬参数速查

> 图表与排版的可直接执行硬参数。
> 这些是**送审直接卡人的数字**，不达标会在技术检查阶段被退回。

---

## 一、图件硬参数

| 项 | 要求 |
|---|---|
| **格式** | TIFF / JPG（🔴 EPS 不推荐；多面板图先单图转 PDF 再合并） |
| **分辨率** | 🔴 **按图类型三档**（PPP 原文，v2 审计补）：照片 **300 dpi** / 位图线条图 **1000 dpi** / 线条+照片混合图 **500 dpi**；标本照片按 600 dpi 准备可通吃各大刊 |
| **单图大小** | 🔴 **<10 MB** |
| **总文件大小** | 🔴 **<50 MB** |
| **图中字体** | sans serif 优先：Arial、Helvetica；或 Times New Roman、Symbol、Courier |
| **单图宽度（双栏刊）** | 单栏 **<85 mm** ／ 双栏 **<180 mm** |
| **图注** | **只看图注就能把图看明白** |
| 色彩 | 推荐彩图（**在线版免费彩印**，印刷版收费） |
| 🔴 禁用格式 | GIF / BMP / PICT / WPG（屏幕优化，分辨率太低） |
| 命名 | 如 `Smith-Figure1.tif` |

### 图内规范细节（PPP 原文，v2 补）
- **正文中首次提及处引用图**（even at first mention）；补充图 `Figure S1`；可另附 600 dpi 出版就绪版
- **Panel labels**：大写字母 A, B, C…；置于**每面板左上或左下角**；全图一致；🔴 不加括号/框
- **图注**：一句描述性标题 + 解释所有符号缩写；**引用来源放图注**；🔴 不重复图内已有信息；同一地层柱勿在多图重复
- **Plates 图版**：PPP 🔴 不允许——化石标本图像集一律按 "Figure" 提交
- **Maps**：🔴 不得显示政治争议边界
- **Graphical Abstract**（可选）：最小 **531×1328 px（高×宽）**，缩至 5×13 cm 仍可读（96/300 dpi）

### 少数情况
横版满版（极少见）。

## 二、🔴 Word 缩放铁律（最易犯错）

```
从制图 → 导出 → 最后插入 Word
全程严禁拉对角线或者等比例缩放！
```

**Word 里插图表，禁止拉对角线缩放！**

**后果**：破坏图元比例、分辨率失真、字体变形。返工成本极高。

## 四、制图尺寸与字号

| 项 | 参数 |
|---|---|
| 设计尺寸 | **≤180 mm（宽）× 230 mm（高）** |
| **线条粗细** | **0.25 与 0.5 mm 组合** —— 太细看不清，太粗显粗莽 |

| 数字文字下限 | 🔴 **严禁小于 4 号** |
| 数字文字上限 | **不推荐大于 12 号** |

## 五、构图原则

### 黄金比例（三分之二原则）
- 精确比例 **0.618…**
- 定义：**比值等于较小部分与较大部分的比值**（`a/(a+b) = b/a = 0.618`）
- ✅ **黄金分割法优于三分法**
  - 三分法构图是水平或竖直的**三分之二**
  - 黄金分割构图：**主体边线通常位于三分线上**，兼具三分法的简易与黄金分割的均衡
  - **具有构图均衡的优美性**

### 对称 vs 不对称
| | 适合表达 | 范例 |
|---|---|---|
| **对称** | 严谨、稳定、平衡、分类 | Liang et al. 2016 PPP（化石标本整齐排列） |
| **不对称** | 变化、动态、演化过程 | Fu et al. 2020 Science |

## 六、编号与文件命名（ P9 七要点）

1. **保持原有大小**
2. **使用推荐字体符号**
3. 🔴 **按照在文章中出现的先后编号**
4. 🔴 **给图文件按顺序编号命名**
5. **提供 figure caption（图注）**
6. 单个图 <10 MB
7. ⚠️ **不要分辨率太小、版面过大**

### 表
**在表上**（而非只在上方）有一句表名。

---

## 七、🔴 版权与合规红线

- 🔴 **严禁直接粘贴复制某个已经发表的图**
  - 例外：Open Access，或已申请获得专门使用许可
- 🔴 **修改后必须标注文献来源**
- 🔴 **不使用有政治分歧的地图等**（涉及国界/主权标注）

---

## 八、图件范例来源（找范例的入口）

**参考目标期刊近 3 年内发表的相似论文，或者相近的最新论文 pre-proof 版本。**

- 期刊主页入口：**Articles in press** → *Latest published* → *Top cited* → *Most popular*
- 直接看 **Guide for authors**
- ⚠️ **Pre-Proof / in press / MS**：多参考几篇，**有些文章也有少量不符合要求的地方（自己要取长补短）**

### 优秀版式范例（引用范例）

| 文献 | 值得学什么 |
|---|---|
| Liang et al. 2016 PPP | 多子图排版（A/B/C 分区）；化石标本图版的对称美感 |
| Sun et al. 2015 PPP | 多面板组合 + 综合柱状图 |
| Tian et al. 2019 | 综合柱状图配色 |
| Tian & Benton 2020 Current Biology | 示意图（Predictions 分区）配色 |
| Fu et al. 2020 Science | 放射虫化石镜下照片；不对称美感 |
| Waltham et al. 2022 PPP | Figure 1（地图+剖面）+ Figure 7（综合图）组合 |
| Sun et al. 2022 PPP (in press) | Pre-Proof 版式 |
| Romanò et al. 2021 Nature Geoscience | **REVIEW ARTICLE** 标签 + 综合时序图（含 Prediction 分区） |
| Dal Corso et al. 2024 Science Advances | 高信息密度 REVIEW 全文版式 |

## 九、Table / Figure Caption 的必含要素

| 项 | 要求 |
|---|---|
| 图号 | 按文中出现顺序 |
| 图注 | **自明性** —— 只看图注就能把图看明白 |
| 表名 | **在表上** |
| 缩写 | 图注中首次出现需全拼 + 缩写 |
| 单位 | 标在图注 |
| 来源 | 修改自他人图必须标注 |
